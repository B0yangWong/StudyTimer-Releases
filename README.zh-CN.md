# StudyTimer

一个原生 macOS 学习计时器：流动的计时圆环、简洁的小窗口、按每日目标填色的学习日历。

这个仓库只提供下载、说明和虚构数据的演示图片。源码保持私有。

## 下载

在[最新版本](https://github.com/B0yangWong/StudyTimer-Releases/releases/latest)下载 `StudyTimer-0.1.0-macOS-arm64.zip`。0.1.0 是预览版本，仅提供 Apple silicon 架构，最低目标系统为 macOS 15，目前只在 macOS 27 上检查过。

本次不做苹果公证，也没有 Developer ID 签名，仅使用临时签名。首次打开可能被系统拦截；软件没有经过苹果审核，是否信任由你决定。

## 安装

1. 解压，把 StudyTimer.app 放进应用程序文件夹。
2. 如果有旧版，先正常退出，再替换 app；不要删除学习记录文件夹。
3. 尝试打开。如果系统拦截，请先判断是否信任下载来源，再手动按[苹果说明](https://support.apple.com/guide/mac-help/open-a-mac-app-from-an-unknown-developer-mh40616/mac)处理。不要关闭系统安全检查，也不需要运行解除隔离属性的脚本。
4. 打开 Settings，在 Language 中切换中文；也能调整每日目标、字号和开机启动。

安装包同时提供 SHA256SUMS.txt，可核对文件是否与该版本一致。这不等于苹果审核或开发者身份认证。

## 功能

- 正计时、最长四小时的倒计时，暂停、继续和重置。
- 大窗口和小窗口共用今日累计，包含学习正计时和学习倒计时；新休息记录不计入学习量。
- 按几小时几分钟设定每日目标，日历颜色按比例填满。
- 小窗口可置顶，窗口控制在靠近左上角时显示，倒计时结束有轻柔提醒。
- 圆环流光集中在圆周上，每小时换色；macOS 26 及以上使用原生玻璃控件。
- 睡眠时暂停，唤醒后恢复睡眠前正在进行的计时；正常退出保存并暂停。

## 开机启动

新安装默认关闭。放进应用程序文件夹后，在设置中自行开启；如果需要系统批准，界面会明确提示并提供系统设置入口。登录时只在后台启动，没有状态栏图标，不自动开始计时；正常打开 app 才显示窗口。

如果旧版曾添加 StudyTimer 登录项，新开关会显示它。操作开关后才会移除或换成系统管理的登录项，不改动其他 app 的项目。卸载前请先关闭开机启动。

## 限制与数据

学习记录只存本机，不上传到 GitHub。没有账号、统计上报、云同步或自动更新；记录没有单独加密、自动备份或专门的导出功能。见[隐私说明](PRIVACY.md)。

旧记录不能可靠区分休息和学习倒计时，历史累计保持原样。没有实际重启电脑验证开机启动，也没有完成旧系统、Intel 或另一台干净电脑的安装验证。这些限制不应被自动测试通过掩盖。

更新需要手动下载新版。反馈问题时只描述复现步骤和系统版本，不要上传真实学习记录或私人日历截图。
